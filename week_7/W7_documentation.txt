Program Name:
Food Order Total Calculator

Description:
This program calculates the total payment for a food order.
The user enters the food price and quantity.
The program multiplies price by quantity and displays the total payment.

Files Created:
1. main.py
2. food_order.py
3. test_food_order.py
4. W7_documentation.txt

Bugs Found:

2. The price should not be zero or negative.
3. The quantity should not be zero or negative.

Fixes:
1. Used try and except to handle invalid input.
2. Added validation for invalid price.
3. Added validation for invalid quantity.
4. Created pytest tests to check the program.
