# Week 5 Tutorial 5

## 1. Problem Statement
The cafe needs a simple Python program to calculate the customer bill automatically.

## 2. Inputs
- Customer name
- Coffee quantity
- Tea quantity
- Sandwich quantity

## 3. Outputs
- Customer receipt
- Item quantities
- Total bill amount

## 4. Typical Process Flow
1. Ask the customer name.
2. Ask the quantity of coffee, tea, and sandwich.
3. Calculate the total price.
4. Print the receipt.

## 5. Constraints
- Quantity must be a number.
- Prices are fixed.
- Total must be shown in RM.

## 6. Decomposition
- Get customer input.
- Calculate total price.
- Print the receipt.
- Run the program from main.py.

## 7. Pseudocode
START

Input customer name
Input coffee quantity
Input tea quantity
Input sandwich quantity

total = coffee quantity * 8.50
      + tea quantity * 6.00
      + sandwich quantity * 12.00

Print receipt
Print customer name
Print quantities
Print total

END
