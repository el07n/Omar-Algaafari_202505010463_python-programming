Ticket Registration System

## 4.1 Purpose of the application
A simple Python program for City University Malaysia IT Support team to log and manage student technical support tickets based on priority levels.

## 4.2 Tech Stack
* *Language:* Python 3
* *Version Control:* Git & GitHub

## 4.3 How to use
1. Run main.py.
2. Enter the required information (Student Name, ID, Issue, Location, Priority).
3. The system will assign a technician based on the chosen priority:
   * *High* -> Ahmad
   * *Medium* -> Siti
   * *Low* -> Ali
4. The system will display the complete support ticket summary.
